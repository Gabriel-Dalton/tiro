Notes for the first launch
Your PC is ARM-based The button now offers the native ARM64 build, with no emulation. The x64 build also works if you prefer it.
Windows 10 You may also need Microsoft's free WebView2 runtime. Tiro checks on first run and offers it if it is missing. Windows 11 already has it.
Windows: SmartScreen Unblocking the ZIP is usually enough. If the dialog still appears, choose More info → Run anyway, or read why it shows up.
Mac: opening an unsigned app System Settings → Privacy & Security → Open Anyway. On macOS 14 and earlier, right-click the app and choose Open.

How it works

01Get a Deepgram key

Free from Deepgram's console. New accounts include credit for hundreds of hours.

02Paste it into Tiro

The key stays on your device. Tiro has no server, so nobody else ever holds it.

03Hold, speak, release

The mic is always warm, so even the first word is caught. A quick tap records hands-free.

04Text lands finished

Punctuation, capitalisation, emails and numbers formatted, pasted where you were typing.

The honest fine print

  • You pay Deepgram, not us. Streaming nova-3 is $0.0048 a minute. What a $15/month subscription costs, about 52 hours of dictation costs here.
  • No Electron. The Mac app is native Swift; Windows uses the Edge WebView already on the machine. Small binaries, no bundled browser.
  • Your history stays local. One plain JSONL file you can grep, export, and carry between the Mac, Windows and web versions.
  • Open source, MIT. A fork of mypip-io/tiro, extended to Windows and the web.
