Hold a key. Speak.
Punctuated text, where your cursor is.

Tiro is a free, open dictation tool for Mac, Windows, and your phone. It uses your own Deepgram API key, so there is no account, no telemetry, and no server in between — your voice goes straight to the transcription API.

≈ $0.005 per minute · no subscription
Windows 10 & 11

Tiro for Windows

Tray app. Hold Right Alt in any application and the transcript is pasted into the focused text box. Single EXE, no installer.

Download for Windows Your PC is ARM-based, so this is the native ARM64 build — no emulation. The x64 build also works if you prefer it. On Windows 10 you may also need Microsoft's free WebView2 runtime — Tiro checks on first run and offers it if it is missing. Windows 11 already has it. Right-click the ZIP → Properties → Unblock before extracting, and Windows starts it quietly. If SmartScreen does ask: More info → Run anyway.
macOS 13+

Tiro for Mac

Menu-bar app by MyPip. Hold Fn anywhere and dictate into any app. The original that this project grew from.

Download for Mac Universal — one file for Apple Silicon and Intel. Unsigned, so the first launch needs System Settings → Privacy & Security → Open Anyway (on macOS 14 and earlier, right-click the app → Open).
iPhone, Android, Linux

Tiro Web

A dictation scratchpad: hold the button, speak, and the transcript is on your clipboard before you lift your thumb. Installs to the iPhone home screen.

Open the web app There is nothing to download — open it, then use the Install button in the top corner to put it on your home screen. Works on Linux, ChromeOS, Android and any older machine. It cannot type into other apps — you paste — which is a rule of the platform, not a missing feature.

How it works

01Get a Deepgram key

Free at console.deepgram.com — new accounts include enough credit for hundreds of hours.

02Paste it into Tiro

The key stays on your device. Tiro has no server, so nobody else ever holds it.

03Hold, speak, release

The mic is always warm, so even the first word is caught. A quick tap records hands-free.

04Text lands finished

Punctuation, capitalisation, emails and numbers formatted — pasted where you were typing.

The honest fine print

  • You pay Deepgram, not us. Streaming nova-3 is $0.0048/min — a $15/month subscription buys the same as ~52 hours of dictation here.
  • No Electron. The Mac app is native Swift; Windows uses the Edge WebView already in Windows 11. Small binaries, no bundled browser.
  • Your history stays local. One plain JSONL file you can grep, export, and carry between the Mac, Windows and web versions.
  • Open source, MIT. Fork of mypip-io/tiro extended to Windows and the web.
