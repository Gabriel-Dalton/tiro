Getting your Deepgram API key

Tiro has no accounts and no subscription. It talks straight to Deepgram, the service that turns your speech into text, using a key that belongs to you. Here is how to get one.

About two minutes No credit card You only do it once
  1. 1

    Make a Deepgram account

    Go to console.deepgram.com and sign up. It is free and it does not ask for a card.

    Partway through, it asks “What would you like to explore first?” and offers Speech to Text, Text to Speech and Voice agent. Choose Speech to Text — that is the one Tiro uses. It only decides what your dashboard shows first, so it is not a choice you can get wrong.

  2. 2

    Open the API Keys page

    Look at the menu down the left-hand side. There is a section called Manage, and API Keys sits in it, directly under Dashboard.

  3. 3

    Create a key

    Click the green Create a New API Key button.

    • Name it anything you will recognise later. “Tiro” is fine.
    • Expiration: Never. A key that expires will stop Tiro working on a random Tuesday for no visible reason.
    • Ignore “Advanced”. Nothing under it matters here.

    Then press Create Key.

  4. 4

    Copy it straight away

    Deepgram shows you the key once. It cannot show it to you again — in the console’s own words, “secrets are not recoverable”. Copy it the moment it appears.

    It is a 40-character jumble of letters and numbers. That is what a key looks like; nothing has gone wrong.

    Closed the page too soon? Nothing is broken and nothing is lost. Delete that key with the bin icon on the right and make another. Keys are free and you can have as many as you like.

  5. 5

    Paste it into Tiro

    Open Tiro, put the key into the field that asks for it, and press Save & test.

    If it worked, Tiro tells you your credit balance. Hold the button, say something, and you are done.

If something goes wrong

Tiro says the key was rejected

Usually the copy grabbed a stray space or missed a character off the end. Paste it again, carefully.

If that does not fix it, check in the Deepgram console that the key is still in your list and has not expired.

There is already a key in my list — can I use that one?

If it is called “Auto-generated Playground API key”, no. Deepgram makes that one for you when you try their Playground, and it expires within hours. It sits there looking exactly as usable as a real key and then quietly stops working.

Make your own, as in step 3.

I have lost my key

Delete it in the console and make a new one. It takes ten seconds and costs nothing.

That is also the fix if your key ever ends up somewhere public — deleting it stops it working immediately.

The things people reasonably worry about

What is this going to cost me?

A new Deepgram account comes with $200 of credit, which is roughly 430 hours of dictation. After that it is about 46 cents an hour, charged by Deepgram for the seconds you actually speak.

There is no subscription and nothing renews. Tiro takes no cut — we never see your money or your key.

Where does my key actually live?

On your own device. The Mac app keeps it in a file only you can read, Windows in encrypted storage, and the web app in your browser’s local storage.

It goes to Deepgram and nowhere else. Tiro has no server to send it to.

How careful do I need to be with it?

Treat it like a password: it is how Deepgram knows the spending is yours. Keep it out of screenshots, chat messages and public posts.

If it does get out, delete it in the console and make another. That is the whole recovery process.
